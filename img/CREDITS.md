## img/moves/*.svg: exercise drawings
From Everkinetic (https://github.com/everkinetic/data), an open data project based on
everkinetic.com by Greg Priday, licensed CC BY-SA 4.0. The files are used unchanged; the file
names keep Everkinetic's exercise numbers. Which drawing goes with which Goku exercise is set in
js/muscles.js (ART).

## img/muscles.svg: muscle map
Adapted from "Muscles front and back.svg" by OpenStax, Tomáš Kebert and umimeto.org
(https://commons.wikimedia.org/wiki/File:Muscles_front_and_back.svg), CC BY-SA 4.0.
